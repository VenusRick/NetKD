**实验周期**: 2025年12月7日 - 2025年12月19日

---

## 📋 一、项目概述

### 1.1 研究背景与目标
NetKD 是一个**基于多教师知识蒸馏的加密网络流量分类框架**，旨在解决加密流量分类中**高精度**与**低延迟部署**之间的矛盾。

| 指标 | 目标 | 实际达成 |
|------|------|----------|
| 教师模型准确率 | ≥97% | **98.77%** |
| 学生模型准确率 | ≥96% | **98.12%** |
| 参数压缩比 | ≥50% | **83%** (8.0M→4.72M) |
| 极致轻量化 | - | **97.04%** @ 0.70M参数 |

### 1.2 核心技术路线

```
┌─────────────────────────────────────────────────────────┐
│               NetKD 三阶段流程                          │
├─────────────────────────────────────────────────────────┤
│  Stage 1: 教师模型训练                                   │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐                │
│  │DenseNet  │ │ConvNeXt  │ │MobileNet │                │
│  │121+ECA   │ │ V2+ECA   │ │ V3+ECA   │                │
│  └────┬─────┘ └────┬─────┘ └────┬─────┘                │
│       └────────────┼────────────┘                        │
│                    ▼                                     │
│  Stage 2: Stacking 集成 (MLP元学习器)                    │
│                    │                                     │
│                    ▼                                     │
│  Stage 3: 知识蒸馏 → 轻量级学生模型                      │
│  (RepViT / GhostNet / MobileNetV3)                      │
└─────────────────────────────────────────────────────────┘
```

## 🏆 五、核心成果总结

### 5.1 最佳配置推荐

| 场景 | 推荐模型 | 精度 | 参数 |
|------|----------|------|------|
| 最高精度 | DenseNet121-ECA (教师) | 98.77% | 8.0M |
| 精度优先部署 | RepViT-M0.9 (学生) | 98.12% | 4.72M |
| 平衡型 | GhostNet-100 (学生) | 98.05% | 3.91M |
| 移动端 | MobileNetV3-Small (学生) | 97.40% | 1.02M |
| IoT/极低资源 | MobileNetV2-0.5 (学生) | 97.04% | 0.70M |

### 5.2 关键超参数

| 组件 | 参数 | 最佳值 |
|------|------|--------|
| 蒸馏 | Temperature (T) | 3 |
| 蒸馏 | Alpha (α) | 0.3 |
| 蒸馏 | 损失函数 | CE + Forward KL |
| 教师训练 | lr / epochs | 1e-3 / 50-65 |
| 学生训练 | epochs | 50-85 |
| MAE预训练 | mask_ratio | 0.6 (EfficientNet) |

### 5.3 技术创新

1. **多教师 Stacking 集成**: MLP 动态融合异构教师，集成 98.70%
2. **轻量 ECA 增强**: +0.50% 精度，仅 +0.01M 参数
3. **KD 超参优化**: 系统搜索确定 T=3, α=0.3 最优
4. **负面结果记录**: 明确 SimCLR 不适用于流量分类
