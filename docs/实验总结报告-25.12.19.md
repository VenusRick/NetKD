# NetKD 项目实验总结报告

**创建日期**: 2025年12月19日  
**项目名称**: NetKD - 基于知识蒸馏的网络流量分类  
**实验周期**: 2025年12月7日 - 2025年12月19日

---

## 📋 执行摘要

本项目通过知识蒸馏技术实现了高效的网络流量分类模型。主要完成了6个系列实验，涵盖教师模型训练、预训练策略对比、知识蒸馏优化和消融研究。**最佳结果达到98.77%准确率（教师模型）和98.12%准确率（学生模型，参数量减少80%）**。

### 关键成果

| 指标 | 数值 |
|------|------|
| 最佳教师模型准确率 | **98.77%** (DenseNet121-ECA) |
| 最佳学生模型准确率 | **98.12%** (RepViT-M0.9) |
| 参数量压缩比 | **83% ↓** (8.0M → 4.72M) |
| 轻量化极限 | **97.04%** @ 0.70M参数 (MobileNetV2-0.5) |
